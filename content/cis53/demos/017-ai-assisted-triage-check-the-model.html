AI-assisted triage: a confident answer, checked against the logs

A model is given six alerts from the Demo 15 capture and asked to triage them. Its answer sounds sure of itself (99% confidence). Check every claim against the evidence. The answer file was written by the instructor to show common failure modes; it is not the output of a specific product.

Download and open

  • class5-alert-bundle.json — the six alerts, the asset list and the approved AI services
  • class5-llm-triage-answer.md — the model's answer, to be checked
  • class5-hunt.pcap — the capture behind the alerts, for checking

01Read the answer once, then list its claims.

cat class5-llm-triage-answer.md
Answer

Make a table: one row per factual claim. There are about nine: the beacon interval, a downloaded executable, the ATT&CK technique, the direction and size of the AI session, the verdicts on A2, A3, A6, and so on. You cannot judge a summary; you can judge claims.

02Claim: 'beaconing every 60 seconds'.

jq -r '.alerts[] | select(.id=="A1") | .evidence' class5-alert-bundle.json
Answer

Wrong detail. The evidence says mean gap 87.4 s with a coefficient of variation of 0.04. A reader who writes a detection from 60 seconds will miss it. Verdict on the host (suspicious) is right, one number is wrong.

03Claim: 'downloaded an executable (MZ header visible)'.

zeek -r class5-hunt.pcap && cat files.log | head
zeek-cut host uri resp_mime_types < http.log | grep assets-front
Answer

Invented. There is no file transfer to that host except a 43-byte GIF. Nothing in the bundle mentions an executable or an MZ header. The model borrowed the usual malware story. Always ask: which line of which log says that?

04Claim: 'T1071.004 (DNS)'.

# T1071.004 is Application Layer Protocol: DNS. What protocol does the beacon use?
zeek-cut service < conn.log | sort | uniq -c
Answer

Wrong technique. The beacon is HTTP on port 80, so the closer match is T1071.001 Web Protocols. DNS is used only for the one lookup. The sub-technique number matters because a wrong ID sends the next analyst to the wrong detections.

05Claim: 'uploaded about 750 KB to the AI service: data exfiltration'.

jq '.alerts[] | select(.id=="A4") | {evidence, intel}' class5-alert-bundle.json
zeek-cut id.orig_h id.resp_h orig_bytes resp_bytes < conn.log | grep 198.51.100.30
Answer

Direction reversed. About 751,700 bytes were received; the host sent 2.5 to 9 KB per session. The destination is on the approved list. Recommending a block of a service the business relies on is a harmful action produced by one reversed word. This is the most expensive error of the five.

06Claim: '99% confident'.

# What would it take to say 99%? Where did the number come from?
Answer

No basis. Brown and Roberts (Ch. 2) ask for the collection method, the date and the context behind a judgment, and a stated confidence level with reasons. A number with no method is decoration. Replace it with: High confidence A1 is not normal for a kiosk (regular schedule, outside destination, first-seen domain); moderate confidence it is malicious, until we check the kiosk.

07What the model got right.

jq -r '.alerts[] | select(.id=="A2" or .id=="A3" or .id=="A6") | .id + " " + .intel' class5-alert-bundle.json
Answer

It correctly closed A2, A3 and A6 as internal, regular and harmless, and it linked A5 to A1. That is real time saved, which is why people use these tools. The lesson is not that the model is useless; it is that the right half and the wrong half look identical.
