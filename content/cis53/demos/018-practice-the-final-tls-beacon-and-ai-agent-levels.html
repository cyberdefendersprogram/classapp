Level 3 practice: the default certificate

About 15 minutes of office traffic, almost all of it encrypted. Threat intelligence says one outside server is a C2 server. Two hosts call out on a fixed schedule over TLS 1.2, and only one is the beacon. You never see the messages. You see who talks, when, how often, what the ClientHello offers, and what each server's certificate says about itself.

Level 5 practice: the bot and the issue

An AI bot triages GitHub issues, as in the February 2026 Clinejection attack. You get its network capture, its tool-call log and its approved-destinations list. Two issues contain instruction-like text and only one made the bot leak tokens. Find the issue, the file, the destination and the timing.

Starter commands

These only show you where to look. You still have to read the output and decide.

# Level 3: who sends ClientHellos, to which server name, and when
tshark -r level3.pcap -Y "tls.handshake.type==1" \
  -T fields -e frame.time_epoch -e ip.src -e tls.handshake.extensions_server_name

# Level 3: the cipher suites one ClientHello offers, and a server certificate
tshark -r level3.pcap -Y "tls.handshake.type==1 && ip.src==10.0.0.15" -V | less
tshark -r level3.pcap -Y "tls.handshake.type==11" -V | less

# Level 5: every HTTP request, with timing and size
tshark -r level5.pcap -Y "http.request" \
  -T fields -e frame.time_relative -e http.request.method -e http.host -e http.request.uri -e http.content_length

# Level 5: the issues the bot read, and its own log
tshark -r level5.pcap -Y "http.response" -T fields -e http.file_data

A method that works on both

  • Count first. How many connections, hosts and names? An odd count is a lead.
  • Look at timing. Human browsing is bursty. A fixed gap is a schedule (Demo 15's regularity idea).
  • Separate lookalikes. A second host also runs on a schedule, and a second issue also contains attack text. What else is different (certificate, cipher list, message sizes, what the bot did next)?
  • Write down the evidence. Packet numbers, filters, log lines. Several Final questions ask you to prove it.
